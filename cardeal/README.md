# Cardeal Project

The Cardeal project is a monorepo structure designed to manage various components of the Car Dealership application ecosystem.

## Project Structure

- `apps/`: Contains the frontend client application.
  - `client/`: A Next.js-based web application built with React, TypeScript, and Tailwind CSS.
- `packages/`: Contains shared packages and libraries used across the applications (e.g., UI components).
- `docs/`: Project documentation and guides.

## Frontend Client (@cardeal/client)

The frontend client is the primary user interface for the Car Dealership application, providing a responsive experience built with modern web technologies.

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Getting Started

To run the frontend application:

1. Navigate to `apps/client`
2. Install dependencies (if not already handled)
3. Run `npm run dev`

> Built line by line locally
